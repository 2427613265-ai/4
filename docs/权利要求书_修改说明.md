# 权利要求书优化说明

对照 CN119933044A 独立权利要求中的编号方式与施工循环写法，对初稿权利要求书作了闭环改写。技术内容（分区、两阶段、跳仓、张力判据、影响线选仓、线形指标）未改，只把步骤写成可循环执行的编号流程。

## 对照来源（CN119933044A 权利要求1）

该专利独立权利要求的循环骨架为：

- 定义 `i≥1`，`i` 为正整数，`i` 的起始值为1；
- 对第 `i` / 第 `i+1` 个施工对象依次作业；
- 判断第 `i+1` 个是否为最后一个；若否，将 `i+1` 赋值给 `i`，返回前面的施工步骤。

从属权利要求中另有“返回步骤S6”“返回步骤S82”的判定闭环。

## 初稿问题

1. 独立权利要求只有 S1–S4 的一次性叙述，第一阶段跳仓和第二阶段吊索区浇筑都用“逐批次……直至完成”，**没有批次编号，也没有返回语句**，无法形成施工循环。
2. 权利要求2用“重复S32至S33”，没有 `q` 编号，也没有“赋值后返回”，且会把 `H₀` 是否重置写不清楚。
3. 权利要求3只写到“选取……作为本批次浇筑对象”，**未写明浇筑**，批次循环完全依赖独立权利要求中并不存在的闭环。
4. 原权利要求5缺编号；权利要求6的监测步骤无编号、无“若否/若是”分支；权利要求8写成“根据权利要求1至9”，引用范围错误。

## 本次改写

| 循环 | 编号 | 闭环写法 |
| --- | --- | --- |
| 第一阶段非吊索区跳仓 | 第 `i` 浇筑批次，`i≥1`，起始值为1 | S5：若仍有未浇非吊索区湿接缝，将 `i+1` 赋值给 `i`，返回 S4 |
| 第二阶段吊索区浇筑 | 第 `N` 浇筑批次，`N≥1`，起始值为1 | 并入独权 S6；S7：若仍有未浇吊索区湿接缝，将 `N+1` 赋值给 `N`，返回 S6 中的第二阶段浇筑 |
| 跨中区段扩展（权利要求2） | 第 `q` 次，`q≥1`，起始值为1 | S33：若 `(H₁−H₀)/H₀≤15%`，将 `q+1` 赋值给 `q`，返回 S32（`H₀` 保持不变） |
| 包络线监测反馈（权利要求6） | 步骤 S81–S84 | S84：未超阈值进入下一批次；超阈值则调整后再进入下一批次 |

第二阶段不用 `k` 而用 `N`，是为了与权利要求5中标高测点编号 `k`（`Δh_k`）区分，写法上也对应 CN119933044A 后段权利要求对 `N` 的用法。

同步修改了说明书“发明内容”和“具体实施方式”中的对应步骤，避免权要与说明书脱节。

## 说明书摘要

初稿摘要仍按“逐批次……直至完成”一次性叙述，未与独权 S1–S7 的 `i`/`N` 闭环对齐。现改为：保留分区、两阶段、跳仓及免配重效果；写明第 `i`、第 `N` 浇筑批次及“将 `i+1` 赋值给 `i` 并返回”“将 `N+1` 赋值给 `N` 并返回”；补入跳仓为沿纵桥向间隔至少一个吊索节段。全文 292 字，不超过 300 字。张力判据与影响线选仓属于从属权利要求细化，摘要不展开以免超字。
