## 二、建议摘要

本发明公开一种皮带输送机五防故障快速定位系统及方法。针对现有五防保护信号多点串联接入、故障无法点位溯源、单点异常易引发大范围停机等问题，在不改动原生产主控皮带启停权限的前提下，增设独立于主控的采集监控单元，并沿皮带廊道分布式布置远程输入模块；将跑偏、打滑、撕裂、堵料、拉绳等保护装置改为独立通道接入；远程模块就地完成信号消抖、滤波和通道诊断，经冗余工业以太网将点位信号上传；上位机按“皮带编号—传感器位号—故障类型”进行可视化告警，并对故障分级、动作频次和运行参数做趋势预警。本发明可将故障定位由沿线人工排查缩短至秒级点位提示，并降低单点非本体故障扩大停机范围的风险。

## 四、技术领域

本发明属于带式输送机安全监测与工业自动化控制领域，具体涉及一种面向皮带输送机五防保护装置的分布式信号采集、故障点位定位、故障分级及隐患预警系统及方法。可应用于冶金烧结、矿山、港口、电力等长距离带式输送场景。

## 五、背景技术

### 5.1 应用场景

在炼铁烧结生产中，皮带输送机是贯穿进料、配料、混匀、烧结、成品整粒及返矿等全流程的核心连续输送设备。其运行是否稳定，直接关系到烧结机利用系数、成品矿质量和产线安全。

烧结皮带工况具有以下特点：

1. **高温老化：** 部分皮带长期输送高温烧结矿，皮带老化和摩擦发热风险高。
2. **锐器刺穿：** 原料夹带锋利钢构件、料斗钢板脱落、检修遗留金属杂物等，易刺穿皮带。
3. **偏载：** 长距离、大倾角皮带数量多，物料偏载突出，易诱发跑偏。
4. **堵转打滑：** 大块、杂物堵斗或机头堆料，可导致皮带堵转、打滑。

炼铁厂现场按要求为皮带配置五防标准化保护装置，即跑偏、打滑、撕裂、堵料及拉绳保护。烧结线全年非计划停机中，由上述五类故障引发的停机占比较高；单次皮带撕裂或堵料造成的停机检修可达 4～12 小时，直接带来产能损失和能耗升高。因此，皮带故障的预防、及时发现与精准定位具有明确的实用需求。

### 5.2 现有技术方案

现有皮带机五防保护的典型做法是：

1. 将同一条皮带上若干保护开关的信号**串联**后，接入生产主控 PLC 及电气回路。
2. 电气回路或 PLC 收到故障后立即停止本条皮带，并按上下游联锁停止关联皮带，以限制故障扩大。
3. 中控人员根据 HMI 上的皮带级报警通知维护人员。
4. 维护人员到现场对保护装置**逐一排查**，确认动作点后反馈中控，再恢复生产。

该“现场装置感知 + PLC 联锁管控 + 人机闭环处置”体系，能够适应烧结高温、多尘、强磨损环境，并在老旧产线上起到基本保护作用。

### 5.3 现有技术存在的问题

1. **只能报“哪条皮带有故障”，不能报“哪一个保护装置动作”。** 串联回路将多个开关合成一个开关量，中控无点位信息。
2. **故障排查耗时长。** 以约 150 m 皮带为例，两侧可敷设近 10 个拉绳开关；拉绳动作停机后，维护人员只能沿通廊逐点查找，处理一个信号常需多人耗时半小时以上。简单信号异常即可造成烧结机停机半小时以上，不适应连续化快节奏生产。
3. **“一断全断”。** 串联回路中任一点断线、误动作或装置失效，整段保护信号失真或直接停机，难以区分本体故障、接线故障和抖动误报。
4. **联锁粒度粗。** 轻故障与重故障往往同等停机，单点非本体故障可能触发烧结系统大范围停机。
5. **缺少预防性手段。** 现有系统以事后停机为主，对皮带温度、料流、动作频次等缺乏趋势监测和隐患预判，难以提前干预撕裂、大面积堵料等重大事故。
6. **装置与工况匹配不足。** 现场存在保护装置选型不当、五防装置故障率高、失效频发等问题，进一步放大了定位难、误停机的矛盾。

因此，需要在尽量不干扰原生产运行的前提下，解决保护信号的点位级采集与可视化溯源、缩短排查时间，并避免单条皮带的信号异常拖垮整条烧结系统。

## 六、发明目的 / 要解决的技术问题

本发明要解决的技术问题包括：

1. 如何在**不占用、不改写原生产主控启停权限**的条件下，把五防保护由“皮带级报警”提升为“装置点位级定位”。
2. 如何适应皮带廊道距离长、点位分散、高低落差大、粉尘与电磁干扰强的现场条件，保证采集连续、可扩展。
3. 如何抑制机械振动造成的瞬时误报，并诊断传感器断线、短路、失电等通道故障。
4. 如何区分重故障与轻故障，避免单点非本体故障引发全域停机。
5. 如何利用运行数据实现隐患预警，推动由事后停机向预防性维护转变。

## 七、技术方案

### 7.1 总体思路

本发明采用“**监测与控制解耦**”的总体架构：

- 新建一套**独立闭环的采集监控系统**，专职负责皮带配套传感器、测点及保护装置的就地采集、逻辑甄别、数据上传和远程状态监视。
- 该系统与原生产主控 **CPU、点位、通讯资源均不共用**，不直接执行皮带启停，不替代原工艺联锁。
- 将传统串联保护回路改为 **一点一通道** 接入，使每一保护装置的编号、安装位置和故障类型均可上传。
- 在采集侧完成消抖、通道诊断和故障分级；在上位侧按“皮带编号—传感器位号—故障类型”可视化溯源，并形成趋势预警。
- 分级结果、通道诊断结果可通过独立通讯或独立点位**提供给**原生产主控，供其按重/轻故障优化上下游联锁；是否采纳、如何停机，仍由原生产主控决定。

由此，故障定位在监测系统内闭环完成，生产安全联锁仍由原系统负责，调试或检修监测系统时不中断皮带正常启停。

### 7.2 系统组成

系统至少包括：

1. **现场五防保护装置：** 跑偏开关、打滑开关、撕裂检测装置、堵料开关、双向拉绳开关等，安装于机架、机头、机尾等相应位点；可扩展料流检测、温度检测等测点。
2. **就近汇接单元：** 廊道中继接线箱及编号挂签的弹簧端子排，将各路屏蔽信号电缆物理归集后转接，避免把长距离多芯电缆直接拉入中控。
3. **分布式远程 IO：** 沿廊道分段就近布置，每个保护装置独占一个数字量输入通道；模块可在本地完成防抖、滤波、阈值判断，并诊断断线、短路、供电缺失。
4. **冗余工业以太网总线：** 远程 IO 以级联或环形方式接入，单链路断点时其余测点仍可上传。
5. **独立采集监控 PLC：** 部署于电气室（实施例中为电气楼六楼新增采集 CPU），运行采集组态程序，对通道信号做逻辑甄别、故障分级和数据归档。
6. **网络隔离与上位监控：** 采集 PLC 以独立网口将现场总线网与上位监控网隔离，仅单向推送监测数据；HMI 按三级树状结构显示并声光报警，提供历史趋势。

**信号流可概括为：**

保护装置 → 独立屏蔽电缆 → 中继接线箱 → 远程 IO 独立通道（就地预处理 + 诊断）→ 冗余总线 → 采集监控 PLC（甄别、分级、归档）→ 隔离网口单向上传 → HMI 点位级告警与趋势分析；（可选）分级结果 → 原生产主控联锁优化。

### 7.3 点位独立上传与可视化溯源

破除传统串联架构，每条皮带的跑偏、打滑、撕裂、堵料、拉绳等装置均以独立两芯或三芯屏蔽电缆接入对应远程 IO 通道。故障发生时，上位机可在秒级显示：

- 皮带编号；
- 传感器位号 / 安装位置（如机头、机尾、廊道某段）；
- 故障类型（如“3# 皮带机头跑偏开关动作”）。

维护人员无需全线排查即可前往故障点。HMI 同时记录各传感器近期动作频次和持续时长，为频发区段的预防性维护提供依据。

### 7.4 分布式冗余采集网络

针对线路长、点位散、落差大、干扰强的廊道，采用控制器集中运算、远程 IO 就近布点的分层架构：

- 远程 IO 就近安装，缩短传感器电缆，减少耗材和施工量；
- 总线支持分站扩展，新增皮带或保护点只需增加模块并入现有总线，不必改主控架构；
- 冗余通讯（如介质冗余环网）在廊道线缆局部破损时，未受影响分站继续上传；
- 采集网与监控网物理隔离，监控侧异常不倒灌现场采集过程，也不影响原生产联锁网络。

### 7.5 边缘预处理与通道级诊断

远程 IO 内置本地可编程逻辑（实施例中为模块自带的现场逻辑），在模块侧完成：

1. 软件消抖 / 滤波，滤除皮带机械振动引起的瞬时抖动，减少误报警；
2. 单端口、单通道独立诊断，识别断线、短路、失电；
3. 将诊断报文与过程数据一并上传，使“保护动作”与“回路故障”可区分。

这样，主站只处理有效事件，运维可区分“开关动作”和“接线/供电故障”，避免把通道故障当成工艺故障沿线盲查。

### 7.6 故障分级、误动作屏蔽与临时解锁

在采集 PLC 程序及上位软件中设置：

1. **重故障 / 轻故障分级：** 例如撕裂、拉绳急停、确认性堵料等可作为重故障；瞬时跑偏、可自恢复抖动等可作为轻故障（具体阈值由现场工艺确定）。
2. **误动作屏蔽：** 结合消抖时间和动作持续时长，屏蔽瞬时抖动。
3. **检修临时解锁：** 经授权后对指定点位临时屏蔽，避免检修作业本身触发大范围停机；解锁有时限和审计记录。

分级结果用于：

- 监测画面差异化告警（颜色、闪烁、声光级别不同）；
- 作为原生产主控优化联锁的输入，避免“任何信号都全域停机”。

监测系统本身仍不直接启停皮带。

### 7.7 隐患预警

采集监控 PLC 归集多维度数据，例如：保护动作频次与时长、料流有无、皮带温度（若接入模拟量）、运行时间等。上位平台建立趋势和阈值模型，在频次异常升高、温度持续偏高、料流异常等情况下提前告警，便于在撕裂或大面积堵料发生前干预。

预警模型的具体算法可以采用阈值比较、滑动窗口频次统计等工程常用方法；本发明的要点在于**用点位级、带时标的保护与运行数据支撑预防性维护**，而不限于某一种数学模型。

## 八、发明关键点（创新点）

**（1）监测与生产主控的物理隔离架构**

新建采集监控系统完全独立于原生产主控 PLC，只做皮带保护及测点的就地采集、逻辑甄别和数据上传，不执行皮带启停。监测与控制解耦，消除监测系统调试、检修对正常生产的干扰。

**（2）面向长廊道的分布式远程 IO 冗余组网**

控制器与沿廊道布置的远程 IO 构成冗余工业以太网（级联 / 环网）。单链路断点仅影响断点后受影响分站（环网时可通过对向路径恢复），避免集中 IO 超长布线，也避免通讯单点失效造成全线监测失联。

**（3）五防装置点位独立上传与中控可视化溯源**

每个保护装置独占通道，上位机按皮带编号、位号、故障类型秒级定位，替代“皮带级报警 + 全线人工排查”。

**（4）分级判定、抖动屏蔽与授权临时解锁**

在监测软件 / PLC 中区分重、轻故障，抑制瞬时误报，并提供检修临时解锁。向原主控提供分级信息，降低单点非本体故障引发全域停机的概率。

**（5）基于点位运行数据的隐患预警**

归集温度、料流、动作频次等数据，由事后停机转向趋势预警和预防性维护。

## 九、有益效果

与现有串联保护 + 人工沿线排查方式相比，本发明能够：

1. **定位从“皮带级”到“点位级”，排查从半小时以上降到分钟级到达现场。** 中控直接给出装置编号和位置，无需通廊逐点查找。
2. **监测系统故障或调试不影响生产启停。** 独立部署、不占用主控点位和网络。
3. **误报和通道故障可识别。** 就地消抖 + 通道诊断，减少振动误停机，避免把断线当成工艺故障。
4. **过保护风险下降。** 重、轻故障分级显示，并可支持主控侧分级联锁，降低单点异常扩大停机范围。
5. **施工与扩展成本优于超长集中 IO。** 就近布点减少电缆；总线级联便于后期加皮带、加测点。
6. **具备预防性维护条件。** 动作频次和过程量趋势可在重大撕裂、堵料前给出干预窗口。

## 十一、具体实施方式（优选实施例）

以下结合图 1 给出一优选实施例。所举控制器型号、远程 IO 型号、协议名称用于说明可实现性，不构成对保护范围的限定。

### 11.1 硬件配置（优选）

- **采集监控 PLC：** 西门子 S7-1500 系列 CPU 1513。该规格足以承载全厂皮带开关量采集、分级和上传；双网口可将现场总线网与上位监控网隔离。
- **远程 IO：** 图尔克 TBEN-S2-8DIP。防护等级 IP65 / IP67 / IP69K，工作温度 −40 ℃～+70 ℃，可耐受粉尘、水冲洗和高低温。模块提供 8 路 PNP 数字量输入、4 组 M12 五针端口；针脚 1 可切换为传感器供电，单通道具备 0.5 A 短路保护。支持 PROFINET，兼具 Modbus TCP、EtherNet/IP，便于后期混接模拟量模块（如 TBEN-S 系列模拟量模块）。
- **组网：** PROFINET，双 M8 以太网口内置交换，手拉手级联；兼容 PROFINET 系统冗余及 MRP 介质冗余环网。通讯快速启动小于 500 ms，断线恢复后自动重连。单链路断点时，环网可经反向路径恢复；若为纯级联，则仅断点后分站受影响，不会造成与断点无关的全线失联。
- **工程实施：** 在 TIA Portal 中导入图尔克 GSDML 完成 IO 组态。现场总线采用 TBEN-S2-8DIP 接入 CPU 的优化总线架构，布线简洁，后期备件和技术资料易于获取。

### 11.2 现场安装与接线

1. 跑偏、打滑、撕裂、堵料、双向拉绳等装置按工艺安装于机架、机头、机尾对应位点。
2. 每一装置配置独立两芯或三芯屏蔽电缆，沿廊道桥架敷设至就近中继接线箱。
3. 接线箱内弹簧端子排按点位编号挂签、汇流转接，完成物理归集。
4. 转接后各路信号就近接入本段 TBEN-S2-8DIP 的对应输入口，**一装置一通道**，消除串联回路“一断全断”。

### 11.3 边缘处理与总线上传

1. 各通道在 IO 模块内做软件消抖和有效性判定，滤除机械振动瞬时误触发。模块本地逻辑（ARGEE 一类现场可编程功能）可承担滤波和阈值判断，降低主站负荷。
2. 有效信号经模块内 PROFINET 协议栈封装为实时报文，经双路冗余以太网口汇入总线。
3. MRP 下任一链路中断时，冗余路径在 500 ms 内切换，上传不中断。
4. 报文至中控独立部署的 S7-1513。CPU 程序完成逻辑甄别、故障分级和归档；单通道诊断信息同步上传，用于提示断线、短路、失电。

### 11.4 上位显示与处置闭环

1. CPU 经上位网口将数据**单向**推送至 HMI 服务器，采集网与监控网隔离。
2. HMI 按“皮带编号—传感器位号—故障类型”三级树展开；不同故障以颜色和闪烁区分。
3. 故障时声光报警，并显示类似“3# 皮带机头跑偏开关动作”的点位信息。维护人员由“收到报警”到“抵达现场”可做到分钟级，而不再全线排查。
4. 历史趋势画面回溯各传感器动作频次和持续时长，对频次异常升高的区段安排预防性维护。
5. 需要时，将分级后的重/轻故障以通讯或独立点位送给原生产主控，由原主控按优化后的上下游联锁停机或限机；采集系统不改写原启停程序。

### 11.5 本实施例相对集中 IO 方案的实施效果（工程说明）

- 分布式就近布点，减少超长电缆。
- 软硬件独立，不占用原主控点位与通讯资源，无生产误操作路径。
- 总线可扩展，新增皮带和测点不必更换 CPU。
- 双网口隔离避免监控网异常干扰现场采集。

## 十二、替代实施方式

在不脱离本发明构思的前提下，至少包括以下等同替换：

1. **控制器：** 可采用其他品牌、同等处理能力的工业 PLC 或工业 PAC，只要独立于生产主控并完成本发明的采集、分级和上传功能。
2. **远程 IO：** 可采用其他高防护（建议 IP65 及以上）、宽温、带通道诊断的数字量模块；通道数不限于 8。
3. **总线：** 除 PROFINET / MRP 外，可采用 EtherNet/IP、Modbus TCP 或其他具备冗余或可级联的工业以太网。冗余形式可以是环网、双总线或主站级冗余。
4. **测点类型：** 在开关量五防之外，可在同一总线上混接温度、速度、电流、料位等模拟量，用于预警，不改变独立通道定位的核心。
5. **边缘预处理位置：** 消抖和滤波可在远程 IO 本地完成，也可在采集 PLC 内完成，或两者结合。
6. **与原主控的关系：** 最低限度为完全旁路监测、仅 HMI 提示人工；进一步可将分级结果硬接点或通讯送给原主控。无论哪一种，采集系统都不直接取代原启停回路。
7. **应用对象：** 不限于烧结皮带，凡长距离、多开关串联导致无法点位定位的带式输送机均可采用。
