# 撰写说明

本案只写独权。交底书第3节欲保护点、第2.2节完整方案和图5一并作为权1的事实来源。交底书称底边为「斜线」，权利要求改为「斜边」，指倾斜的直线边，不是曲线边。

## 1. 技术问题与机制

**技术问题：** 振动筛有效宽度约3000mm，进料斗宽仅800mm～1200mm。进料斗直落到筛面时，前端约1/3筛面无料，且受料不均引起偏析和摆振。进料斗下截改为拉式皮带后偏析消除，但落点仍集中，约1/4筛长方向面积未发挥作用。料斗与筛之间加振动给料机可以分散，但要较大高度差和前后空间，建设成本高、维护量大。需要一种占空间小、无动力、能把窄料流展宽到筛面上的布料结构。

**机制（均能从交底书直接读出，未作结构推定）：**

- 两块形状、尺寸相同、方向相反的溜料圆弧板相对设置，中间形成由窄到宽的溜料通道。料斗来的矿石落到两块板上，向两侧展开。
- 板沿进料端至出料端呈弧形弯曲。物料带着初速度沿圆弧运动并抛出一段距离，而不是贴着直面滑到落点。
- 两板底边为斜边且倾斜方向相反，出料端宽于进料端，把料流宽度放大到原料料流的三倍以上。
- 支撑杆连在两板之间，承受矿石冲击，避免通道变形。
- 侧板与两块圆弧板连接，并固定到料斗壁，与进料端的相接一起构成安装。

## 2. 独权每个特征为什么必要

| 特征 | 为何必要 | 删一法 |
| --- | --- | --- |
| 用于安装在料斗出料口 | 短安装关系，锚定进料端和侧板与料斗壁的连接；料斗不是本装置零件 | 留。不写振动筛：筛是受料对象，不参与展宽机制，写入会把布到皮带或其他受料面的相同结构排除在外 |
| 两块形状、尺寸相同且方向相反地相对设置的溜料圆弧板，中间形成溜料通道 | 完整方案的载体。单板只能向一侧抛料，对向设置才能把中央料流展成宽幅 | 留 |
| 进料端与料斗相接，出料端宽于进料端 | 闭门造车时必须能画出由窄接料、向宽抛出的通道；图5呈喇叭形，有益效果要求展宽三倍以上 | 留 |
| 沿进料端至出料端呈弧形弯曲 | 欲保护点「必须是弧形」；没有弧，物料不能沿圆弧抛出，退化为直面溜槽，与皮带改造后仍集中落料的问题同类 | 留 |
| 底边均为斜边且倾斜方向相反 | 欲保护点「底边是斜线」；两板反向后斜边方向必须相反，否则出料口无法稳定展宽 | 留 |
| 支撑杆连接于两板之间 | 欲保护点；交底书写明用于在矿粉冲击下不产生形变。没有连接件，两板在独权里是悬空的 | 留。不写「三根」「厚皮钢管」 |
| 侧板与两板连接，并用于固定至料斗的壁 | 欲保护点「侧板……固定在料斗壁上」，是装置在料斗上的固定界面 | 留。不写「螺栓」 |

未写入独权的实施例特征及理由：尖头端焊接料斗壁 → 预留从权（焊接是工艺，尖头是进料端一种外形）；侧板螺栓可拆卸 → 预留从权（对应「便于更换」，不是展宽机制）；支撑杆为三根厚壁钢管、沿流向间隔布置 → 预留从权。交底书未给弧半径、斜边倾角、板厚，独权不编数值。

## 3. 两段式

最接近的现有技术是进料斗直落、拉式皮带、或料斗与筛之间的振动给料机，都没有对向溜料圆弧板。因此前序只保留产品名称和安装位置；两板、斜边、弧形、支撑杆、侧板全部放在特征部分，避免把发明贡献写进前序。

## 4. 闭门造车（4.1）

盖住说明书和附图，只看权1：

| 检查 | 结论 |
| --- | --- |
| 装置装在哪 | 料斗出料口。能确定工位 |
| 料从哪进、从哪出 | 进料端与料斗相接，出料端宽于进料端。能画出喇叭形通道 |
| 两板如何摆 | 形状尺寸相同、方向相反、相对设置。能画出对向弧形通道 |
| 板如何弯、底边如何切 | 沿流向弧形弯曲；底边为斜边且倾斜方向相反。能画出侧视三角形轮廓 |
| 两板如何连在一起 | 支撑杆在两板之间并连接两板 |
| 如何固定在料斗上 | 侧板连两板，并固定至料斗壁 |
| 孤立部件 | 四件均有位置或连接关系 |
| 有无使用步骤 | 无「落到板上」「沿圆弧飞出」等过程句 |

**结论：权1通过。**

## 5. 因果链（4.2）

| 效果 | 机制 | 权1落脚点 |
| --- | --- | --- |
| 料流宽度放大到三倍以上，筛面利用率提高 | 对向弧形板形成由窄到宽的通道，斜边反向切开料 | 方向相反相对设置；出料端宽于进料端；底边为斜边且倾斜方向相反 |
| 相对均匀地铺到受料面，消除偏析和摆振 | 物料沿圆弧抛出一段距离，而不是集中砸在一点 | 沿进料端至出料端呈弧形弯曲 |
| 不需要振动给料机的高度差和前后空间 | 无动力、附在料斗出料口的溜道 | 用于安装在料斗出料口；通道由两板形成 |
| 冲击下不塌、可装在料斗上 | 杆撑两板，侧板固定到料斗壁 | 支撑杆连接于两板之间；侧板用于固定至料斗的壁 |

制造简单、成本低、便于更换：简单和成本由无动力溜道本身带来，不必再写电机或液压。「便于更换」依赖螺栓可拆，不在展宽因果链上，放到从权。

## 6. 范围检验（4.4）

| 规避 | 是否落入权1 | 处理 |
| --- | --- | --- |
| 支撑杆改成钢板肋、槽钢，不是钢管 | 仍落入「支撑杆」 | 材质和下位截面放从权 |
| 两板之间不用杆，改用周边满焊成箱 | **可能不落入**（无支撑杆） | 有意保留杆：交底书把杆列为欲保护点，且独权需要两板之间的连接件。若发明人要求覆盖满焊箱体，需把「支撑杆」改成「连接件」并在说明书补两个以上下位 |
| 侧板改销轴、压板，不用螺栓 | 仍落入「用于固定至料斗的壁」 | 螺栓在从权 |
| 进料端不是尖头，改成矩形短边 | 仍落入 | 尖头端在从权 |
| 单块弧形板，或两块同向平行 | **不落入** | 对向、反向是展宽机制，单板/同向不是本方案 |
| 两块平面斜板（无弧）做成喇叭口 | **不落入** | 欲保护点要求必须是弧形 |
| 底边水平或弧形底边 | **不落入**「斜边」 | 与欲保护点一致 |
| 把装置接到皮带或矿仓而不是振动筛 | 仍落入 | 独权未锁振动筛 |

## 7. 形式自查

- 主题为产品「矿石分散布料装置」，无方法、无「及其应用」
- 产品用结构描述，无使用步骤
- 一项一个句号；约273字
- 每个「所述X」均有引出：料斗在前序「料斗出料口」首次出现；进料端、出料端在「具有进料端和出料端」首次出现；四件在「包括」中首次出现
- 料斗出料口与通道出料端用不同词，不混
- 无附图标记、无「例如/最好是」、无数值
- 未把焊接、螺栓、三根钢管写入独权
- 功能性用语仅「用于安装」「用于与料斗相接」「用于固定至料斗的壁」，均为安装关系，主体仍是结构
