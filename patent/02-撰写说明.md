## 1. 技术问题与机制

**技术问题：** 在钢板沿冷矫直机出口辊道连续通过时，以干式方式同时做到：(a) 板宽方向上相邻圆形清扫区之间的间隙带以及板边被刷到；(b) 刷体与板面的接触状态可随板厚调节，且各盘与板面保持平行；(c) 刷落粉尘被约束在罩内并导向排出。

**机制（交底书未写清部分为 `[推定]`，已按本领域原理写入独权关系，待发明人核对）：**

- 覆盖：清扫圆盘可转动，刷体在朝向板材的一侧，刷体相对板面做圆周运动，具有沿板宽和沿输送方向的速度分量。前排圆盘沿宽度方向间隔排列，相邻前排圆盘之间留出间隙，以避免盘体在同一排内干涉；后排圆盘落在该间隙的宽度位置上，并与两侧前排圆盘沿宽度方向部分重叠，使钢板行进时的扫过条带连续衔接。
- 调高：升降机构驱动升降框架相对安装基础沿靠近或远离板材的方向平移（区别于翻转式活动框架），圆盘与除尘罩同装于该框架，调高时各盘平行、罩对清扫区的包络保持。
- 收尘：除尘罩罩设全部圆盘，出风口与排风装置连通，罩内形成指向出风口的负压气流。

## 2. 独权每个特征为什么必要

| 特征 | 为何必要 | 删一法结论 |
| --- | --- | --- |
| 清扫圆盘可转动，朝向板材的一侧有刷体 | 圆周剪切的载体；没有则干式圆盘清扫不成立 | 留独权 |
| 框架为升降框架，升降机构驱动其平移 | 解决板厚变化时压入量失控；写成平移是为区别 CN204294650U 的液压翻转 | 留独权 |
| 升降机构连接于安装基础 | 力的传递路径要闭合，否则升降机构没有反力端 | 留独权 |
| 前排沿宽度间隔排列，至少两个；后排至少一个，位于前排相邻两盘的宽度间隙处 | 在盘体互不干涉的前提下填补前排间隙带 | 留独权 |
| 后排圆盘与相邻前排圆盘沿宽度方向部分重叠 | 只对间隙不对重叠，切点附近仍可能漏扫；前排相邻两盘本身并不重叠，故不能写成「任意相邻圆盘均重叠」 | 留独权 |
| 除尘罩与升降框架连接并罩设各圆盘 | 清扫区封闭的载体，且罩随框架平移，保持包络 | 留独权 |
| 出风口与排风装置连通 | 相对仅有盖板挡飞溅，负压捕集不成立 | 留独权 |
| 被配置为安装于冷矫直机出口输送辊道上方 | 安装关系，用于闭门造车时确定圆盘和罩相对板材的位置；辊道本身不作为装置零件列出 | 保留配置关系，不把辊道写成元件 |

未写入独权的实施例特征及理由：五组 / 前 3 后 2（板宽变化后盘数会变）→ 权 2；电机+减速器+传动轴 → 权 3；直径与重叠量数值 → 权 4；四角液压缸+同步控制件 → 权 5；柔性密封帘及 50mm～100mm → 权 6；导流板 → 权 7；风量调节阀 → 权 8；独立调速 → 权 9；钢丝刷、风机和烟囱 → 权 10。独立调速在 CN204294650U 已有变频电机，不能为独权挣创造性。

## 3. 分支树的设计意图

```
1 独权（两排填隙 + 平移调高 + 罩口抽风）
├─2 ── 4     L2/L3 布置几何 → 直径与重叠量端点（相对 CN204294650U 的 V 形五盘，权 2 是最有把握的回退）
├─3           L3 单组传动链（不锁死电机在框架顶部，因文字与附图冲突）
├─5           L2 四角液压缸 + 同步控制件
├─6           L4 柔性密封帘 + 数值端点
├─7           L3 罩内导流板朝向出风口
├─8           L5 进风管路风量调节阀
├─9           L4 每组独立且可调速
└─10          唯一多项从权：钢丝刷 + 风机烟囱
```

一级从权 2、3、5、6、7、8、9 均直接引用权 1，避免单链塌缩。权 4 只引用权 2，在 3+2 几何下落到数值。权 10 为末端汇总，其后不再设多项从权。

权 2 放在最前：审查员通常先评权 2、权 3；前 3 后 2 且前排中心连线垂直于输送方向、后排在正后方间隙，是相对 V 形布置最清楚的结构差别。
