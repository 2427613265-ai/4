## 1. 技术问题与机制

**技术问题：** 筛宽约3000mm，斗宽仅800mm～1200mm。直落则前端约1/3筛面无料，并偏析、摆振。改拉式皮带后偏析消除，落点仍集中。加振动给料机要高度差和前后空间。需要无动力、贴在料斗出料口、能把窄料流展宽的结构。

**机制：**

- 两块同形反向圆弧板相对，中间由窄到宽。矿石落到两板上向两侧展开。
- 板沿流向起弧，进料端陡、出料端缓，物料沿圆弧抛出一段距离。
- 底边为反向斜边，两板夹角沿流向增大，出料端宽于进料端。
- 杆横跨两板，长度随间距加大，挡住冲击引起的张口变形。
- 尖头端焊在料斗壁，侧板螺栓可拆，便于换件。

## 2. 分支树

```
1 独权（对向圆弧板 + 反向斜底边 + 由窄到宽通道 + 板间支撑杆）
├─2            侧板接两板，螺栓可拆固定到料斗壁
├─3            进料端尖头，焊接到料斗壁
├─4            三根圆管，沿流向间隔
├─5            杆沿流向排列、杆长递增、相互平行
├─6            两板夹角沿流向增大
├─7            单板弧边三角形；进料端高、出料端低；由陡立过渡为平缓
├─8            出料端宽度为进料端的三倍以上
├─9            流向同向弯曲、内表面内凹相对；杆在通道内接内表面
└─10           唯一多项：尖头焊接 + 侧板螺栓 + 三根厚壁钢管
```

权2～9均直引权1，避免单链塌缩。权4管数量和截面，权5管长度变化，二者独立：三根等长圆管落入权4不落入权5；两根以上递增长杆落入权5不落入权4。权10为实施例汇总，其后不再被引用。

## 5. 用词

- 一律「两个溜料圆弧板」，与修改后独权一致，不用第一/第二。
- 「料斗出料口」对「溜料通道出料端」，不混。
- 「圆管」在权4（从图读形状），「厚壁钢管」在权10（从文字读材料和壁厚）。
- 「陡立 / 平缓」相对进料端、出料端而言，不另引入水平面夹角。
- 无附图标记、无「例如 / 最好是」、无过程句（不写「物料飞出」）。
